AL DÍA RD – Logo, diseño nuevo e Instagram
==========================================

QUÉ TRAE ESTA CARPETA
  noticias.py        -> busca noticias, hace los resúmenes, arma la página nueva y las imágenes de Instagram
  instagram.py       -> publica en @aldiardnews (3 noticias cada 3 horas = 24 al día)
  logo.py            -> el programa que hizo el logo (no hay que correrlo otra vez)
  requirements.txt   -> ahora incluye "pillow" para hacer las imágenes
  fuentes/           -> la letra Inter que usan el logo y las imágenes
  docs/img/          -> el logo, el favicon y la foto de perfil de Instagram
  .github/workflows/noticias.yml -> ahora también publica en Instagram

1. SUBIR
   En el repo aldiard: Add file -> Upload files -> arrastra todo lo de esta carpeta
   -> Commit changes. Te va a reemplazar noticias.py y requirements.txt; eso está bien.
   NO borres docs/noticias.json: ahí están las noticias que ya tienes.

   La carpeta .github no se sube bien arrastrando. Abre en GitHub el archivo
   .github/workflows/noticias.yml que ya tienes, dale al lapicito (Edit),
   borra todo, pega el contenido nuevo de noticias.yml y dale a Commit changes.

2. FOTO DE PERFIL DE INSTAGRAM
   Usa docs/img/perfil-instagram.png. Bio sugerida:
   "Noticias de RD y de los dominicanos en EE.UU. 🇩🇴🇺🇸" + enlace aldiard.com

3. PROBAR
   Actions -> Publicar noticias -> Run workflow.
   Tarda unos 5 minutos, porque espera que GitHub publique las imágenes antes de mandarlas a Instagram.
   Si sale en verde, revisa @aldiardnews.
   Si sale en rojo, abre el paso que falló y copia el error para arreglarlo.

AJUSTES (en noticias.py)
   IG_POR_CORRIDA = cuántas noticias van a Instagram cada 3 horas (Instagram permite hasta 100 al día).
   MAX_NUEVAS     = cuántas noticias nuevas busca por corrida (más = más gasto de IA).

OJO CON EL TOKEN DE INSTAGRAM
   Dura 60 días. El programa intenta renovarlo solo en cada corrida.
   Si un día Instagram deja de publicar, saca un token nuevo en Meta y cámbialo en el secreto IG_TOKEN.
